# 60 天教材索引

教材已備妥不代表課程完成。完成狀態以原檢查表及實際上課筆記為準。

- 教材：`Course_DayN.md`，不綁定日期。
- 上課紀錄：`Note_DayN_YYMMDD.md`，使用台灣當地實際上課日期；同日續課更新同檔，跨日續課另建筆記。
- 既有筆記依原紀錄對應 Day 1、Day 2，保留內容與完成狀態。
- 例：第 3 天於 2026-11-01 上課，記錄為 `Note_Day3_261101.md`。此為命名示例，不表示已開課。
- 每日新對話建議命名 `Course_DayN`；如需區分續課可加日期。
- 範例是完整、可獨立執行的教學切片，沒有省略號或待填函式；各課另列整合回正式專案的步驟。它們不構成已驗收的完整生產系統。
- 設計、文件、驗收日提供完整設計示範；其輔助程式只示範契約或流程，不能取代實際人工與環境驗收。
- 上課逐段講解，確認理解再往下；教學與三題複習完成後才開啟當日獨立實作題。
- 約一小時：5 分鐘目標、20 分鐘範例與設計、5 分鐘複習、10 分鐘需求討論、15 分鐘實作與審查、5 分鐘筆記。必要時拆課，不省略驗收。
- 不預先填寫學生答案、心得、測試結果或效能數據。
