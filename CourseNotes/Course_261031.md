## 教學與完整範例
用語約定：今天使用 Executor(執行器)、Caller(呼叫端)、SSH Client(SSH 用戶端)。後續以英文稱呼；Caller 指呼叫執行器的程式，SSH Client 指負責 SSH 通訊的用戶端物件，兩者角色不同。

今天是純設計課，以完整介面契約及情境走查驗收。對話中提供模擬程式輔助教學；正式資料模型與連線留待後續課程實作。學員保存的完整清理範例見 `../Samples/Day1_261031_caller_and_executer.py`（原始檔名，尚未更名）。

- 逐段講解手寫 `__init__` 與 `@dataclass` 的關係、parameter(參數) 與 attribute(屬性)、`frozen=True`、`slots=True`、型別提示、keyword-only(僅限關鍵字) 參數、`return` 與 `raise`、`try/except/else` 與 `finally`。
- `frozen=True` 阻止一般屬性重新賦值；`slots=True` 在本例限制新增未宣告屬性。結果模型的完整設計於 Day 03 繼續。
- 範例採 modern Pythonic 寫法，逐項解釋新語法；Caller 使用 assert 比對預期，不修改實際結果。

範例需求：呼叫端要求透過 SSH（Secure Shell，安全遠端連線協定）在一台主機執行一條指令，取得結果，再自行判斷是否符合測試預期。

輸入：主機、連接埠、使用者、私鑰位置、由呼叫端提供的解鎖資料、known_hosts 位置、指令、連線各階段限制、指令總期限。具體欄位與預設值留待資料模型課決定。

輸出契約：指令完成且取得完整結果時，回傳 stdout（Standard Output，標準輸出）、stderr（Standard Error，標準錯誤）、exit_code（結束代碼）與指令階段耗時；保留原始文字及換行。指令階段耗時從送出執行請求前到完整結果取得，不含建立連線。

失敗契約：設定無效、連線失敗、主機金鑰驗證失敗、使用者身分驗證失敗、通道或讀取失敗、指令逾時，以可區分的例外回報，不假造正常結果。具體例外類別於後續課程定義。指令非零仍回傳完整結果。若無法取得結束代碼，即使已有輸出，也不當作完整結果。逾時可附帶已讀取的部分輸出，但不假造結束代碼；實作細節留待逾時課程。

責任：呼叫端取得驗證資料、提供指令與限制、判斷結果；執行器驗證輸入、建立及核對連線、執行、讀取雙串流、遵守期限、嘗試清理自己建立的資源。每次呼叫擁有一條連線，成功與失敗皆嘗試關閉。關閉本機連線不保證遠端子程序停止。

必要範圍：單一主機、單一指令、同步執行、結果保真、失敗分類、期限、清理。後續功能：並行、重試、資料庫、報告、命令列操作。

情境走查：

| 情境 | 執行器行為 | 呼叫端判斷 |
| --- | --- | --- |
| 輸出 serverlab-ubuntu\n，結束代碼 0 | 回傳原始輸出、空 stderr、0、耗時 | 比對預期主機名稱與代碼 |
| stdout 為 partial\n、stderr 為 failed\n，代碼 7 | 三項皆保留，正常回傳結果 | 若預期 7，可判定測試通過 |
| 使用者身分驗證失敗 | 拋可辨識的驗證例外，嘗試清理 | 沒有該目標指令的執行結果 |
| 超過指令總期限仍未結束 | 拋逾時例外，嘗試清理；部分輸出不可冒充完整結果 | 指令是否造成遠端副作用可能未知 |

## 實作重點
- **1. 需求要描述可觀察的行為**
  - 以輸入、輸出、失敗與範圍說清楚承諾，避免只說「支援 SSH」。
  - 先定契約，再決定函式、類別與檔案。
- **2. 分開執行責任與測試判斷**
  - 執行器取得結果；呼叫端決定結果是否符合預期。
  - 非零代碼也可能是測試預期，因此不一律轉為例外。
- **3. 完整結果與執行器失敗分開表達**
  - 完整結果含兩條輸出、結束代碼與耗時。
  - 驗證失敗沒有目標指令結果；逾時可能已有部分輸出或副作用，但沒有完整結果。
  - 不用空字串、None 或假造代碼掩蓋失敗；這些值可能與合法結果混淆。
- **4. 資源所有權與範圍要明確**
  - 誰建立連線，誰負責嘗試關閉；本例由執行器負責。
  - 不在執行器內互動取得密語；讓呼叫端選擇憑證來源。
  - 先完成同步單指令，後續再加入並行與重試，避免同時增加過多決策。

## 獨立程式練習：模擬磁碟檢查

### 題目與契約
- 建立不連網路的模擬版本，以假連線驗證 Caller 與 Executor 的責任分工。
- 使用 `@dataclass(frozen=True, slots=True)` 定義 `CommandResult`，包含 `stdout`、`stderr`、`exit_code`。
- 模擬磁碟使用率檢查：使用率小於或等於門檻回傳 0，大於門檻回傳 7；完整結果必須保留實際代碼。
- 模擬身分驗證失敗時拋出 `AuthenticationError`；模擬執行時間超過指令期限時拋出 `TimeoutError`，不需真實等待。
- Executor 在 `finally` 嘗試關閉假連線；不加入自動重試、遠端檔案刪除或遠端程序停止機制。
- 使用 pytest 驗證回傳 0、回傳 7、身分驗證失敗、指令逾時四種情境，並檢查每種情境的連線清理。
- 原設計情境中的 Caller 固定預期 7；本檔單元測試則分別驗證 Executor 在低於及超過門檻時回傳正確代碼，因此可分別預期 0 與 7。
